# Frame

Where a block sits on a free slide, in stage px of the deck's page size.

## Example Usage

```typescript
import { Frame } from "sanka-sdk/models";

let value: Frame = {
  x: 7325.63,
  y: 4768.31,
  w: 7565.43,
  h: 385.89,
};
```
